# ARMAS（Apex Reservation Management & Alert System）

Apex Legendsのランクマッチ予約管理ツールです。カレンダーから日時を選んで予約すると、
Discordチャンネルへ自動通知されます。

## フォルダ構成

```
ARMAS/
├── index.html   ← これを開いて使う
├── css/
│   └── style.css
└── js/
    └── app.js
```

## 使い方

1. `ARMAS` フォルダごと、好きな場所（デスクトップや任意のフォルダ配下）にダウンロード・配置します。
2. フォルダ内の **`index.html`** をブラウザ（Chrome / Safari / Edge など）で開きます。
   - macOS / Windows：ダブルクリックで開けます。
   - iOS：Safariで `index.html` を開いてください（Filesアプリからも開けます）。
3. 右上の「設定」ボタンから **Discord Webhook URL** を入力し、「保存」を押します。
   - Discordのチャンネル設定 →「連携サービス」→「Webhookを作成」で発行できるURLです。
4. （任意）ランクマップ情報を表示したい場合は、`api.mozambiquehe.re` で無料発行できる
   **Apex Legends APIキー**も同じ設定欄に入力してください。未設定でも予約機能自体は使えます。
5. カレンダーで日付・時間を選び、必要なら備考を入力して「予約する」を押すと、
   Discordへ通知が送られます。

## データの保存範囲について

- 予約内容・設定（Webhook URLなど）は、開いている**ブラウザ内（localStorage）**にのみ保存されます。
- そのため **端末やブラウザが違うと予約一覧は共有されません**（例：自分のPCとiPhoneでは別々のデータになります）。
- 友人と使う場合は、各自が個別にこのフォルダをダウンロードし、各自の環境で
  Discord Webhook（同じチャンネル宛でOK）を設定してください。予約時の通知は
  同じDiscordチャンネルに集約されるので、「誰がいつ予約したか」は通知ログから確認できます。
- 予約データそのものを全員で共有したい場合は、サーバーを使った構成への拡張が必要です。
  （必要になったタイミングで対応可能です）

## v1.0の範囲

- 通知先：Discordのみ（LINE Notifyは2025年3月末にサービス終了しているため非対応）
- 予約データの共有：なし（各自のブラウザ内で個別管理）
