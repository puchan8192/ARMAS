
## 主な機能

- カレンダーによる日時選択・予約（予約者名・予約先・現在のランク・備考の入力）
- 予約ごとのステータス管理（募集中／確定／キャンセル）
- 予約への返信機能、Discordの通知リンクからの「参加する／参加しない」回答
- Discord・LINE（グループ）への自動通知（新規予約・返信・キャンセル・参加可否回答）
- 予約日時のAPEXランクマッチマップ情報表示（api.mozambiquehe.re連携、残り時間のリアルタイムカウントダウン）
- 予約一覧・カレンダーのリアルタイム同期（Supabase Realtime）
- 現在のオンライン人数・入力中のユーザー名の表示
- 履歴・統計ページ（予約者別／ランク帯別／ステータス別の集計、CSVエクスポート）
- ログイン機能（Supabase Auth）と管理者権限
  - 管理者ユーザーのみ、サイドバーに設計書・GitHubリポジトリへのリンクが表示されます
- スマホ幅でも崩れないレスポンシブレイアウト

## 事前準備：Supabaseのセットアップ

1. [supabase.com](https://supabase.com) でプロジェクトを作成します。
2. SQL Editorで`reservations`・`replies`・`app_settings`・`profiles`・`line_targets`の各テーブルを作成します。テーブル定義は`02_詳細設計書.md`を参照してください。
3. `profiles`テーブルはRow Level Security（RLS）を有効化し、認証済みユーザーが閲覧できるポリシーを設定します。
4. LINE通知にはSupabase Edge Functions（`notify-line`, `line-webhook`）を使用します。デプロイ手順・環境変数（LINEのChannel Access Token等）の設定は`02_詳細設計書.md`を参照してください。
5. Authentication機能でユーザーを作成し、管理者にしたいユーザーは以下のSQLで昇格させます。

```sql
update profiles set role = 'admin' where id = '対象ユーザーのUUID';
```

6. プロジェクトの「Project URL」と「anon public key」を、`frontend/index.html`内の`SUPABASE_CONFIG`に設定します。

```html
<script>
  window.SUPABASE_CONFIG = { url: "https://xxxx.supabase.co", anonKey: "xxxxx" };
</script>
```

> **注意**：anonKeyはフロントエンドのコードに直接埋め込まれ、誰でも閲覧できる状態になります。RLSポリシーで許可した範囲までは誰でも操作可能になるため、信頼できる友人内での利用に留めてください。

## 使い方

1. GitHub Pagesで公開されたURL（`https://ユーザー名.github.io/ARMAS/`）にアクセスします。
2. ログイン画面が表示されるので、Supabaseで発行されたメールアドレス・パスワードでログインします（新規ユーザーの追加はSupabaseダッシュボードから管理者が行う招待制です）。
3. ログイン後、サイドバーの「予約する」「予約一覧」「履歴・統計」からページを切り替えられます。管理者ユーザーの場合は、加えて設計書・GitHubリポジトリへのリンクも表示されます。
4. カレンダーで日付・時間を選択し、予約者名（必須）・予約先・現在のランク・備考を入力して「予約する」を押すと、Discord・LINEへ通知されます。
5. 既に予約が入っている日時にはマークが表示され、内容はホバーで確認できます。重複がある場合は登録前に確認ダイアログが出ます。
6. 各予約カードから、ステータス変更・編集・削除・返信ができます。キャンセル・返信時はDiscord・LINEへ通知されます。
7. 「予約一覧」画面では、予約者名・期間で絞り込み検索ができます。
8. 「履歴・統計」画面では、予約者別／ランク帯別／ステータス別の集計とCSVエクスポートができます。

### 通知先の設定について

- Discord Webhook URLとLINEの通知設定は、**全員共通のSupabase設定（`app_settings`テーブル）**で一元管理されています。個別のブラウザごとに設定する必要はありません。
- Apex Legends APIキーのみ、これまで通り各自のブラウザ内（localStorage）に個人設定として保存されます（通知には影響しないためです）。

## データの保存範囲について

- 予約・返信データ、通知設定（Discord/LINE）は**Supabase上で一元管理**されており、誰がどの端末から操作しても、内容は全員にリアルタイムで共有されます。
- ログイン情報・ユーザーの権限（管理者／一般）もSupabase Authおよび`profiles`テーブルで管理されます。
- Apex Legends APIキーのみ、各自のブラウザ内（localStorage）に個人設定として保存されます。

## 通知先について

Discord・LINE（グループ）の両方に対応しています。個人向けのLINE Notifyは2025年3月末にサービス終了しているため非対応です。
